# Python Engineering Standards

1. **Type Annotations**: Annotate all public function parameters and return types using `typing` and PEP 484/585 standards.
2. **Interpreter Standard**: On Linux systems, always run via `python3` (avoid ambiguous `py` commands).
3. **Packaging & Dependencies**: Pinned dependencies in `pyproject.toml` or `requirements.txt`. Use virtual environments.
4. **Clean Code & Formatting**: Follow PEP 8 guidelines. Write descriptive docstrings for all modules, classes, and public methods.
