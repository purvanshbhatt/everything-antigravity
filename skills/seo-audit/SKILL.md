# Technical SEO & Content Optimization

## Overview
Perform end-to-end audits of web pages, documentation sites, and landing pages to ensure top-tier organic indexing and social sharing performance.

## Audit Checklist
1. **Metadata & OpenGraph**:
   - Title tag: 50-60 characters, target keyword in the front.
   - Meta description: 140-160 characters with clear call to action.
   - Social cards: `og:title`, `og:description`, `og:image` (1200x630px), `twitter:card` (summary_large_image).
2. **Semantic HTML Structure**:
   - Strict hierarchical heading structure (exactly one `h1`, logical `h2` and `h3` nesting).
   - Descriptive `alt` attributes on all images.
   - Meaningful anchor text on all internal links (no "click here").
3. **Structured Data (Schema.org / JSON-LD)**:
   - Implement `SoftwareApplication`, `Article`, `FAQPage`, or `Organization` schemas.
4. **Performance & Core Web Vitals**:
   - Largest Contentful Paint (LCP) < 2.5s.
   - First Input Delay / Interaction to Next Paint (INP) < 200ms.
   - Cumulative Layout Shift (CLS) < 0.1.

## Deliverables
- Detailed SEO audit report with prioritized Critical, Warning, and Info tickets.
- Ready-to-inject JSON-LD schema snippets.
