# Canvas Image Processing & Thumbnail Automation

## Overview
Automate batch image manipulation, badge watermarking, dynamic open-graph social cards, and thumbnail generation using Python (`Pillow`/`OpenCV`) and Node.js (`Sharp`/`Canvas`).

## Key Workflows
1. **Dynamic Social Card Generation**:
   - Compute text dimensions and wrap dynamic headings across multiple lines.
   - Render crisp SVG badges, gradients, and typography onto a 1200x630px canvas.
2. **Thumbnail High-Impact Composition**:
   - High-contrast subject isolation against dark/saturated background.
   - Large, legible sans-serif typography (max 4-5 words).
   - Brand icon / logo lockup in corners with subtle drop-shadow.
3. **Asset Optimization**:
   - Automatic conversion to modern WebP and AVIF formats with 80-85% quality factor to achieve 70%+ file size reductions.
