# High-Conversion Copywriting

## Overview
Produce punchy, credible, and persuasive copy for landing pages, technical documentation, release announcements, and promotional emails.

## Writing Rules
1. **Ruthlessly Cut Filler**: Avoid corporate fluff like "streamlining revolutionary paradigms". State directly what the tool does in plain, concrete words.
2. **Benefit Over Feature**:
   - Feature: "Contains an asynchronous SQLite cache."
   - Benefit: "Sub-millisecond query responses, even offline."
3. **Hero Section Architecture**:
   - Eyebrow: Category or badge (e.g., "Open Source Antigravity Suite").
   - Headline: 6-10 words stating the primary transformation.
   - Subheadline: 1-2 sentences explaining how it works and for whom.
   - Primary CTA: Friction-free action (e.g., "Install via CLI", "Explore on GitHub").
   - Social Proof: Star counts, active users, enterprise logos.
4. **Human Touch**: Eliminate stereotypical AI prose patterns: forced triads, empty contrasts, and artificial transitions.

## Deliverables
- Landing page copy sheets with hero, feature breakdown, FAQ, and footer.
- Release notes formatted in Conventional Changelog style.
