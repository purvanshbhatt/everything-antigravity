# Changelog

All notable changes to Everything Antigravity (EAG) are documented in this file.

## [1.0.0] - Initial Release
### Added
- **Core Engine**: `AgentShield` security scanner, `ContextCompactor`, and `AntigravityOrchestrator`.
- **Skills Catalog**: 30 production-ready skills across Business & Marketing, Security, Engineering, Game Development, Multimedia/Video, and Antigravity native orchestration.
- **Specialized Subagents**: 10 purpose-built agent definitions (`code-architect`, `security-guard`, `game-engine-specialist`, `multimedia-producer`, etc.).
- **Workflow Commands**: Executable slash-command specifications (`/boost`, `/review`, `/audit`, `/feature-dev`, `/game-build`, `/video-render`, `/marketing-launch`, `/checkpoint`).
- **Installers**: Universal cross-platform installers for Linux, macOS (`install.sh`), and Windows (`install.ps1`).
- **Antigravity Marketplace Support**: Compliant `.antigravity/marketplace.json` and plugin definitions.
- **Verification Harness**: Automated Pytest suite covering all manifests, schemas, and CLI operations.
