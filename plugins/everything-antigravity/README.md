# Everything Antigravity Plugin

The official plugin distribution package for **Google Antigravity**.

## Installation

### Via Antigravity CLI
```bash
agy plugin install everything-antigravity
```

### Manual Link
Symlink or copy this directory into your Antigravity plugins folder:
```bash
ln -s "$(pwd)/plugins/everything-antigravity" "$HOME/.gemini/config/plugins/everything-antigravity"
```

## Features
- **30+ Production Skills** spanning Marketing, Security, Engineering, Game Development, and Multimedia/Video.
- **10 Autonomous Subagents** ready for multi-tier delegation.
- **Security Guardrails** with AST analysis, prompt-injection defense, and secret scrubbing.
- **Model Context Protocol (MCP)** server integrations.
- **Token Optimization & Compaction** to maximize context window utilization without losing state.
