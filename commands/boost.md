# /boost - Performance & Capability Acceleration

## Purpose
The `/boost` command maximizes the agent's analytical depth, executes context compaction, activates all specialized EAG subagents, and applies strict verification gates.

## Execution Sequence
1. **Context Compaction**:
   - Inspect active session context length. If exceeding 50% of the window, run `eag compact` on historical tool outputs.
2. **Specialized Agent Dispatch**:
   - Deconstruct current task into required domain pillars (Marketing, Security, Engineering, Game Dev, Multimedia).
   - Assign specialized agents with explicit deliverables.
3. **Strict Verification Enforcement**:
   - Mandate test execution before declaring completion.
   - Forbid weakening or deleting tests.
4. **Summary**:
   - Output structured performance report detailing optimizations and milestones completed.
