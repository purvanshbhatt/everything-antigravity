# /feature-dev - End-to-End Feature Development Workflow

## Purpose
Guides the agent through a disciplined feature lifecycle from requirements analysis and interface specification to TDD implementation and documentation.

## Phases
1. **Requirements & Scope**: Define acceptance criteria and edge cases.
2. **Architecture & Contracts**: Define public classes, function signatures, and data models.
3. **TDD Harness**: Write failing unit and integration tests covering positive, boundary, and error paths.
4. **Implementation**: Implement minimum viable code to turn all tests green.
5. **Review & Refactor**: Clean up and optimize while ensuring 100% test pass rate.
