# /game-build - Video Game Prototyping & Mechanic Loop

## Purpose
Scaffolds and builds playable 2D/3D game prototypes, mechanics loops, and scene trees across Godot, WebGL/Three.js, or Canvas engines.

## Workflow
1. **Mechanic Blueprint**: Define player inputs, physics rules (gravity, velocity, friction), collision layers, and game loop timing.
2. **Entity & State Setup**: Set up player, enemies, hazards, and collectibles using ECS or scene tree nodes.
3. **Core Loop Implementation**: Implement deterministic physics update, input handling, and collision resolution.
4. **Juice & Polish**: Add particle effects, camera shake, dynamic audio triggers, and score tracking.
